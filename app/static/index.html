ИНТЕГРАЦИЯ

Один файл. Один запрос.

API для автоматической проверки жюри. Загрузите видео и получите результат по идентификатору задания.

POST

/api/v1/analyze

Передайте MOV в multipart-поле file. Сервер вернёт job_id и HTTP 202.

GET
/api/v1/jobs/{job_id}
Опросите статус: processing, done или failed.
{
  "job_id": "…",
  "status": "done",
  "verdict": "no_violation",
  "violations": []
}
Доступ и обработка
Авторизация
Заголовок X-API-Key. Без верного ключа — HTTP 401.
Файл
MOV / MP4, до 150 МБ, длительность до 180 секунд.
Результат
Вердикт, события, таймкоды и 1–3 JPEG-кадра в base64 для каждого события.
Занятость сервиса
Одна GPU-задача одновременно. Повторный запрос — HTTP 429.
Хранение
Исходник удаляется после анализа. Результат доступен 24 часа; его можно удалить раньше.
