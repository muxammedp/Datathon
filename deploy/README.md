# Перенос ForteVision на GPU-сервер

Рабочий API использует Qwen3-VL-4B в 4-битном формате с локальным LoRA-адаптером. Публичное размещение и Docker пока не проверены. Качество модели и ограничения приведены в корневом [VALIDATION.md](../VALIDATION.md).

## Установка

1. Передайте исходники, `models/Qwen3-VL-4B-Instruct-bnb-4bit` и `models/forte-video-lora-4b-v1`. Исходные видео, XLSX, `.venv`, старые задания и локальный API-ключ переносить не нужно.
2. Проверьте `nvidia-smi`, Docker с поддержкой NVIDIA GPU и совместимый с CUDA 12.8 драйвер. На новом GPU скорость и потребление памяти нужно измерить заново.
3. Запустите `docker compose up --build -d` либо установите зависимости и выполните `python -m uvicorn app.main:app --host 127.0.0.1 --port 8000`.
4. Дождитесь `engine: ready` в `GET /api/health`. Это означает готовность обработки, а не подтверждённое качество. Проверяйте также `automatic_verdict_enabled`.
5. После согласования публикации подключите HTTPS reverse proxy к `127.0.0.1:8000` с лимитом загрузки 150 МБ и таймаутом не менее 300 секунд.
6. С внешней машины проверьте отказ 401 без ключа, POST с `X-API-Key`, получение `job_id` и GET до завершения. Проверьте удаление загруженного оригинала и срок хранения результата.

Базовые веса устанавливает `python scripts/download_video_model.py`. Адаптер переносится отдельно или воспроизводится обучением по корневой инструкции. Переменные старого движка `FORTE_MODEL_NAME` / `FORTE_MODEL_DIR` текущую модель не переключают.

## Настройки и статус сдачи

- `FORTE_API_KEY`: необязательный ключ не короче 24 символов. Без него создаётся `data/api-key.txt`.
- `FORTE_DATA_DIR`: каталог заданий и ключа.
- `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`: рабочая модель загружается с диска.

При `automatic_verdict_enabled: false` сервис возвращает `inconclusive`. Это расширение API не соответствует бинарной схеме сдачи кейса без согласования. Готовность HTTP-сервиса не означает готовность решения для жюри. Типы нарушений и роли людей не размечены и не обучены отдельно.

Docker, домен, сертификат и удалённые POST/GET нужно проверить на фактическом сервере. Локальные тесты их не заменяют.
