# Проверка ForteVision

Дата: 17 октября 2026 года. Проверялась локальная модель Qwen3-VL-2B-Instruct.

## Что готово и что не подтверждено

Реализован локальный интерфейс в палитре Forte, API с ключом, анализ видео локально развёрнутой моделью на GPU, события с таймкодами, JPEG-доказательствами и фиксированными нормативными ссылками. Русские описания формируются по шаблонам категории, а не являются свободным пересказом сцены. Реальный HTTP-путь проверен.

**Это инженерный прототип. Точность распознавания недостаточна для самостоятельных решений о нарушениях.** Есть ложные тревоги и пропуски. Готовность интерфейса и API не означает готовность модели к эксплуатации или гарантированный результат на закрытом тесте.

Публичный адрес не создан. Инстансы Brev не создавались и кредиты не расходовались. Вариант модели 8B подготовлен как настройка, но не запускался и не оценивался.

Показатели относятся к бинарному ответу по видео. Они не измеряют правильность каждого отдельного события, его описания, нормативной категории или доказательства. Ближайшее предсказанное время сопоставлялось с единственным таймкодом XLSX; это ограниченная оценка локализации, особенно при нескольких событиях.

Для сравнения: постоянный ответ «нарушение» на этом наборе даёт 22 совпадения из 42, то есть 52,4%. Текущий детектор по общей доле совпадений этот простой ориентир не превзошёл. Высокую полноту нельзя представлять без числа ложных тревог.

Формат запросов дорабатывался при работе с открытым набором. Дообучения весов не было, но набор не является независимым holdout. Закрытый тест и другой ракурс не проверены; классов нарушений в разметке нет. Для одинаковых Х-4 / Х-47 указаны разные времена — 57 и 68 секунд. Х-5 / Х-48 также идентичны. Дубликаты в оценке используют один вычисленный результат, что отмечено в записях.

Сводка получена одним полным прогоном текущего детектора: описательный поиск кандидатов и компактная повторная проверка. Файлы находятся в `data/evaluation-hybrid`. Более ранний вариант со свободной генерацией описания на обоих этапах дал 18 совпадений из 42 (42,9%), 6 ошибок формата, 14 ложных срабатываний и 4 пропуска среди успешно обработанных видео. Один повторный запрос на исправление формата не устранил эти 6 ошибок. Диагностика показала обрыв длинных описаний до закрытия JSON. Полностью компактный вариант без описательного первого этапа обработал все 42 файла, но дал лишь 17 совпадений (40,5%), TP=3, TN=14, FP=6, FN=19; его максимальное время составило 18,36 с. Поэтому в текущей схеме сохранён описательный поиск, а свободное описание исключено из второго этапа и итогового ответа. Ранние результаты сохранены отдельно в `data/evaluation-final`, `data/evaluation-retry` и `data/evaluation-compact`. При изменении модели, запросов или оборудования оценку необходимо повторить.

Все исходные видео, кадры и описания обрабатывались локально. Внешние AI-сервисы не использовались. В исходный ZIP эти данные и ключ не включены.

## Дополнительный проверенный подход

Обучаемый линейный классификатор по замороженным визуальным признакам Qwen показал 42,5% на пятичастной стратифицированной перекрёстной проверке 40 уникальных видео (TN=7, FP=12, FN=11, TP=10). Преобразование признаков обучалось внутри каждого фолда, точные дубликаты предварительно удалены. На кадр выбирались признаки изображения; для видео объединялись среднее, стандартное отклонение, максимум и среднее абсолютное изменение по 16 кадрам. Регуляризация C=0.01 была задана заранее и не подбиралась по этим результатам. Классификатор не улучшил качество и не включён в рабочий сервис. Проверка нового ракурса не проводилась. Скрипт `scripts/research_classifier.py` и `requirements-research.txt` сохранены для воспроизведения.

## Проверка программной части

- 12 автоматических тестов пройдены: ключ, ограничения загрузки, статусы, ошибки, освобождение очереди, удаление исходника, JPEG, фактическое время кадра при повреждённом хвосте, ограниченный повтор при неверном JSON.
- В этих тестах анализатор заменён синтетическим: они не доказывают качество нейросети.
- Статическая проверка интерфейса: 60 уникальных ID, 43 цели JavaScript, существующие локальные ресурсы, подписи полей, отсутствие небезопасного HTML-вставления. `node --check` пройден.
- Браузерная визуальная проверка и взаимодействия через браузер не выполнены: в сессии отсутствовал доступный управляемый браузер.
- Docker-образ и внешнее размещение не проверены.
- Есть предупреждение Starlette об устаревшей интеграции тестового клиента с httpx; тесты завершились успешно.

В запущенный сервер передано настоящее MOV из набора; анализатор не подменялся.

| Проверка | Результат |
|---|---:|
| Запрос без ключа | HTTP 401 |
| Загрузка с ключом | HTTP 202 |
| Итоговый статус | done |
| Полное время HTTP-проверки | 30.22 с |
| Событий в ответе | 1 |
| JPEG полностью проверено декодером | 3 |
| Исходник удалён после обработки | True |

Этот тест подтверждает работу протокола, формата и обработки одного реального файла, но не правильность его смысловой интерпретации. Подробный результат остаётся локально в `data/validation/api_real_result.json`.
